## 🔁 Review Workflow

1. Go through `questions.md` for a topic — read answer, run the code example.
2. Attempt `practice.md` cold, without looking at answers.
3. Flag anything shaky in that topic's `README.md` under **Weak Spots**.
4. Before the actual interview, only re-review flagged items across all topics.
